Bready Darkroom

Photo editing for web design. Food and portrait filters, curves, levels, batch edits, web-ready export. Works offline. Your photos never leave your device.

Windows

Installs like any Windows program, with a Start menu icon. Windows may show “Windows protected your PC” the first time, because the app isn't code-signed. Click More info → Run anyway.

Download installer Portable version (no install)

Android

Download the APK, open it, and allow “Install unknown apps” for your browser when Android asks. Exports save to Documents › Darkroom and open the share sheet so you can send them to Photos or WhatsApp.

Download for Android

Mac, iPhone, iPad, Chromebook

  1. Chrome or Edge (Mac, Windows, Chromebook): open the app, then click Install app in the top bar, or the install icon in the address bar.
  2. Safari on Mac: File → Add to Dock.
  3. iPhone / iPad: open in Safari, tap Share, then Add to Home Screen.
